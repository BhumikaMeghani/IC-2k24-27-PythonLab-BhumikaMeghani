Part A: Dictionary Programs

The programs in this section practise using dictionaries to store records and perform common operations.

1. Student Database
   Stores student details and subject marks. It supports adding, updating, deleting, and viewing student records, along with reports such as averages, toppers, and grades.

2. Employee Database
   Stores employee details such as ID, name, department, and salary. It supports record management and reports including department-wise payroll, headcount, and salary comparisons.

3. Library Record System
   Stores book details and borrowing information. It supports adding books, issuing and returning books, searching records, and generating library reports.

4. Word Frequency Counter
   Counts the occurrences of words in a text and provides results such as the most frequent words, words that appear once, and frequency groups.

5. Phone Directory
   Stores contact details and phone numbers. It supports adding and updating contacts, searching by name or number, deleting records, and viewing contacts grouped by city.

Part B: Predict the Output

This section contains eight Python dictionary snippets. Each question includes the expected output and a short explanation of the dictionary behaviour being tested, such as aliasing, shallow copying, dictionary comprehensions, setdefault(), key equality, deletion during iteration, pop(), and duplicate keys.

File: PartB/predict_output.txt

Part C: Short Reasoning Questions

This section answers eight questions about dictionary concepts, including copying nested dictionaries, hashable keys, accessing values, update(), safe deletion, reversing dictionary relationships, and lookup time complexity.

File: PartC/short_reasoning.txt

How to Run the Python Programs

Open a terminal in the relevant folder and run a program using Python 3. For example:

python3 student_database.py

Use the corresponding filename for the program you want to run. The text files in Part B and Part C contain written answers and do not need to be executed.
